# 勇者之路 2 玩家版

这是《勇者之路 2》的非官方免费改版。玩家包只包含游戏运行文件和 [Ruffle](https://ruffle.rs/) 桌面运行器。

## 下载与启动

1. 在本仓库的 [Releases](https://github.com/KinMan-ZHR/yongzhezhilu2-player/releases) 下载最新的 `windows-x64.zip`。
2. 完整解压到固定文件夹，双击 `开始游戏.bat`。
3. 如果运行不畅，双击 `开始游戏-兼容模式.bat`。

更新时先退出游戏，再把新版完整解压并覆盖到原文件夹。保持原安装路径与 `game-ui-refactor.swf` 文件名，有助于继续读取原存档。

包内保留 Ruffle 的授权文件。原游戏、角色、音乐和素材的权利归各自权利人所有。
